# Energy Management Services — Market Map

An interactive market map of the energy-management-services landscape (103 companies, October 2026), built for impact-investment research.

**Open the dashboard:** https://sayasivaram.github.io/energy-management-market-map/

- **Market Map:** four quadrants (residential ↔ C&I/utility, hardware ↔ software). Bubble size shows firm size and colour shows each firm's role. Click a quadrant to zoom in. Hover a bubble for the website, a description and the business model.
- **Company Data & Updates:** a sortable table plus add, edit and delete, and CSV/JSON import and export.
- **To Research:** a shared pipeline of startups to look into. "Add to map →" turns an entry into a full company record.
- **Team sharing:** connect a Google Sheet (see `apps-script/Code.gs` and the setup steps in the dashboard's *Investor Notes & Settings* tab) so the whole group sees the same data. Viewing is open to anyone with the link; editing requires the team passcode.

The whole dashboard is one self-contained file (`index.html`), so it also works offline once downloaded. Figures are approximate and for orientation only. This is not investment advice.
